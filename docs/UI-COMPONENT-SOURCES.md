# Component references

## Open status text and light effect, 28/10/2026

Adapted the layered glow/hover technique from [mrhyddenn's Uiverse button](https://uiverse.io/mrhyddenn/moody-badger-62), with [public source in Uiverse Galaxy](https://github.com/uiverse-io/galaxy/blob/main/Buttons/mrhyddenn_moody-badger-62.html). SYNERA keeps text-only status labels, existing Lucide icons, blue/slate colors and the real status values. Button shape, uppercase text, letter spacing and large neon halo are omitted. Glow is smaller, hover-led, finite for the transit icon and disabled for reduced motion. No dependency or remote runtime code was added.
